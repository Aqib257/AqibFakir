✨ Overview

A modern interactive portfolio + professional resume website built with pure HTML, CSS, and JavaScript.
Designed with clean UI, animations, and corporate styling to showcase IT experience and skills.

🔥 Features

✔ 🌙 Dark / Light Mode Toggle
✔ 🎯 Interactive UI & Animations
✔ ⌨️ Typing Effect (Dynamic Roles)
✔ 📊 Animated Counters
✔ 📱 Fully Responsive Design
✔ 📄 Printable A4 Resume (1 Page CV)
✔ 🖼️ Profile Photo Upload (Local Storage)
✔ 🎨 Theme Switching (Multiple Colors)
✔ 📩 Contact Form with Validation
✔ 📋 Copy-to-Clipboard Buttons
